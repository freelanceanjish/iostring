# iostring LinkedIn Company Page Banners

Ready-to-upload cover images for the iostring LinkedIn company page, matched to the website hero domains.

## LinkedIn specifications

| Setting | Value |
|---------|-------|
| Recommended size | **1584 x 396 px** |
| Minimum size | 1128 x 191 px |
| Aspect ratio | **4:1** |
| File format | PNG or JPG |
| Max file size | 8 MB |

Use the **1584 x 396** files for best quality. The **1128 x 191** files match LinkedIn's display size if you need a smaller upload.

## Safe zone

LinkedIn places the company logo over the **bottom-left** of the banner. These images keep that corner darker and simpler so the logo stays readable.

## How to upload

1. Go to your [iostring LinkedIn company page](https://www.linkedin.com/company/iostring/).
2. Click **Edit cover image** (admin access required).
3. Upload **`iostring-linkedin-banner-move-forward-1584x396.png`** (or another banner from the list below if you prefer).
4. Adjust crop if needed and save.
